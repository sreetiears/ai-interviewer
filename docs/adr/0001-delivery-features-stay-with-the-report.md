# 表达特征只进入成绩单，不保留原始音频

模拟面试要给说法方式留证据，但不能让旁路测量改写出题、追问和回合控制。因此每轮考生发言只在内存里算出表达特征，波形随即丢弃；特征写入面试状态，仅供成绩单里的表达维度参考。出题和追问不读这些数字，也不把语速或音高换算成固定加减分。配置可以关掉这份输入。关掉时不复制波形、不计算、不出现进场说明，成绩单与纯文字版本一致。计算失败只把该轮记为缺测，面试继续。摄像头、实时语音模型和演示模式里的假测量都不在这一刀里。

## 考虑过的做法

- 用实时语音模型替换主链路：会让固定台词和题量离开状态图。
- 用公式把语速、音高直接打成分数：不可解释，也会把说法方式误写成能力。
- 把原始音频落盘以便复盘：超出最短保留，而且评测可以用本机录音复现同一计算。

## 后果

直播必须在当轮拿到波形，不能事后从现有状态里补。离线评测走同一个计算，只读本机录音。缺测必须保持为缺测，不能填 0。

成绩卡和文字成绩单都把这个维度叫「表达逻辑」。表达特征只写进这个维度的分数和一段表达说明；核心不足、改进建议以及其他维度不引用这些数字。总分仍由模型综合三个维度给出。

语速用转写字数除以去掉停顿后的发声时长。停顿从连续静音满 300 毫秒起算。填充词只从转写里认「嗯、啊、呃、那个、就是、然后」，不从声音里另判。音高变化是有声段基频的标准差，音量是有声段强度的平均值。有效说话短于 1 秒的轮次整轮缺测；转写为空时，只让语速和填充词缺测。离线脚本要自带转写，不另做语音转写。
