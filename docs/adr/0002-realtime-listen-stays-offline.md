# 实时听感先做离线横评，直播接入以后再决定

方案 B 要让实时模型听考生怎么说，但这一轮只拿同一批录音做横评，不把模型接到正在进行的面试。直播接入仍是后续目标，那一步另做决定：实时模型只听，不替换主链路；出题、追问和台词仍由面试状态图和语音合成负责。结构化面试的出题和追问不读说法判断。以后若单开自由提问，再决定它能不能读。这一轮不建自由提问。表达特征只进成绩单。

## 考虑过的做法

- 现在就把实时模型接到直播：两路费用和同步还没有数据，而且会碰到「表达特征不进追问」。
- 只做离线、不写下后续：后面的人会以为直播接入已经被放弃。

## 后果

本轮产物是横评记录，不是直播客户端。记录里的模型判断叫「说法判断」：这一轮是否犹豫、这一轮有没有说完。它不是「表达特征」；表达特征仍指本机测得的语速、停顿、音高变化、音量、填充词比例和回答时长。直播接入的候选形状是旁路听感。结构化面试不读说法判断。每家模型保留自己的横评记录；以后的合看不能盖掉这些记录。语气和情绪不写进后续计划。以后若增加听法信息，另立一项，不能用这两个词。
